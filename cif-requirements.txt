# cif-requirements.txt
#
# Minimal dependency set for the Counterfactual Influence Flow (CIF) package
# (em_organism_dir/cif/). Pinned to the versions this work was actually
# measured on: CPython 3.12.13 on Apple silicon (M5), macOS, torch MPS backend.
#
# Install with:
#   uv venv --python 3.12
#   uv pip install -r cif-requirements.txt
#
# -------------------------------------------------------------------------
# DELIBERATELY EXCLUDED: unsloth, vllm, bitsandbytes
#
# The upstream pyproject.toml requires all three. They are CUDA-only (unsloth
# and bitsandbytes need compiled CUDA kernels; vllm needs a CUDA/ROCm device to
# initialise) and cannot be installed or imported on Apple MPS / CPU. They were
# removed rather than worked around, and the two upstream code paths that needed
# them were rewritten in pure transformers + peft:
#   * em_organism_dir/cif/model.py  replaces the unsloth fast-model loader
#   * em_organism_dir/cif/train.py  replaces the unsloth + HF Trainer SFT loop
#   * em_organism_dir/cif/generate.py replaces vllm batched sampling with
#     model.generate() and left-padded generation batches
# Nothing in em_organism_dir/cif/ imports unsloth, vllm or bitsandbytes.
#
# Also excluded because no cif module imports them: transformer-heads,
# transformer_lens, neel, neel_plotly, trl, datasets, wandb, gradio,
# statsmodels, scikit-learn, scipy, matplotlib, seaborn, plotly, cmasher,
# mdmm, fire, backoff, ipykernel/ipython/ipywidgets, nbformat, anywidget,
# eai-sparsify, nest-asyncio, tabulate, pydantic.
# -------------------------------------------------------------------------
